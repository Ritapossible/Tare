# Tare logo

Logo A, the "net bar": the outlined bar is what was promised, the solid bar is what arrived, and the
orange dashed gap is the shortfall Tare catches. Colours: ink `#050505`, paper `#f6f6f4`, orange `#f97316`.

| `tare-mark.svg` / `.png` | Mark only, light ink, for dark backgrounds |
